To book Lordship Recreation Ground, contact:

- **Email:** [parksbookings@haringey.gov.uk](mailto:parksbookings@haringey.gov.uk)
- **Phone:** 020 8489 1418

Use these contacts to ask any preliminary questions.

For the full booking process and more information, visit: [https://www.haringey.gov.uk/libraries-sport-and-leisure/parks-and-open-spaces/events-and-activities/events-parks/booking-park](https://www.haringey.gov.uk/libraries-sport-and-leisure/parks-and-open-spaces/events-and-activities/events-parks/booking-park)
